# Automative-Fleet-Management

Dieses Repository enthält eine webbasierte Management-Plattform zur strukturierten Erfassung und Verwaltung von Fahrzeug-Testflotten. Es dient als Interface, um Fahrzeugdaten, Entwicklungsprojekte und technische Aufgaben effizient zu dokumentieren.

## Projektbeschreibung

Die Plattform ermöglicht die digitale Aufnahme von Testfahrzeugen und deren Zuweisung zu spezifischen Entwicklungsprojekten. Sie wurde entwickelt, um eine saubere Datenstruktur für die Verwaltung und Überwachung von Testflotten im Automobilbereich zu gewährleisten.

## Features & erfasste Daten

Das System deckt folgende Informationen ab:

* **Fahrzeug-Details:** Modellbezeichnung, Kennzeichen, Fahrzeug-ID und aktueller Status.
* **Entwicklungs-Projekte:** Zuweisung zu spezialisierten Test- und Fahrzeugprojekten:
  * Erprobungsfahrten & Dauerlauf
  * Software- & Steuergerätetests
  * Hardware- & Komponentenprüfung
  * Flottenlogistik & Standortverwaltung
* **Technische Aufgaben:** Dokumentation von Wartungsintervallen, Inspektionen und Prüfaufträgen.

## Technologien

* **HTML5** (Struktur und Aufbau der Benutzeroberfläche)
* **CSS3** (Styling, Layout und responsives Design)
* **JavaScript** *(falls verwendet, sonst entfernen)*
